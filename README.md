# FitApply 🎯 (v0.3.0)

**ربات هوشمند ارزیابی رزومه، جستجو و ارسال خودکار به آگهی‌های شغلی**

### TL;DR (خلاصه در یک نگاه)
آگهی‌های مرتبط در **جابینجا، جاب‌ویژن، ایران‌تلنت، Remotive (ریموت دلاری)، The Muse و لینکدین** را کشف می‌کند، میزان انطباق مهارتی و حقوقی را می‌سنجد و اگر **Fit** بود، با **مرورگر کروم لاگین‌شده خودتان** ارسال می‌کند.
> 💡 **هوشمندی رزومه در سایت‌های ایرانی:** در پلتفرم‌هایی مانند جابینجا، جاب‌ویژن و ایران‌تلنت که رزومه شما از قبل در پروفایل حساب‌کاربری‌تان تکمیل شده، **هیچ نیازی به فایل PDF نیست** و سیستم مستقیماً با همان رزومه ستاپ‌شده درخواست را ارسال می‌کند! برای سایت‌های خارجی نیز در صورت دادن فایل، فرم‌ها پر و رزومه به شکل امن آپلود می‌شود. در نهایت یک **داشبورد بصری مدرن HTML (بدون نیاز به وب‌سرور)** برای بررسی نتایج در اختیارتان می‌گذارد.

### شروع سریع (۳ مرحله)

**۱. نصب و تنظیم:**
```bash
git clone https://github.com/abolfazl-moeini/FitApply.git
cd FitApply
uv sync
cp config.example.yaml config.yaml
```
*(در `config.yaml` کلمات کلیدی، پلتفرم‌ها و ارائه‌دهنده هوش مصنوعی — `antigravity` یا `litellm` — را مشخص کنید.)*

**۲. نقد و اعتبارسنجی رزومه قبل از ارسال (جدید در v0.2.0):**
```bash
uv run fitapply audit --resume cv.pdf
```
*(ایرادهای ساختاری، کمبود کلمات کلیدی و امتیاز ATS رزومه را بی‌تعارف به شما نشان می‌دهد.)*

**۳. باز کردن کروم با پورت دیباگ (یک‌بار لاگین کنید):**
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.fitapply-chrome"
```
در پنجره بازشده وارد اکانت جابینجا، جاب‌ویژن، ایران‌تلنت یا لینکدین شوید.

**۴. اجرا:**
```bash
# اجرای تستی (فرم‌ها پر می‌شوند ولی ارسال نهایی کلیک نمی‌شود)
uv run fitapply run --resume cv.pdf --dry-run

# اجرای تعاملی (تایید شما پیش از هر ارسال)
uv run fitapply run --resume cv.pdf

# شکار مشاغل ریموت بین‌المللی رایگان (بدون نیاز به کلید یا اسکرپینگ)
uv run fitapply run --resume cv.pdf --sites remotive,themuse --dry-run

# اجرای تمام‌خودکار
uv run fitapply run --resume cv.pdf --auto
```

### گزارش‌دهی و داشبورد ۳ لایه (جدید در v0.2.0)

| دستور | کارکرد |
| :--- | :--- |
| `uv run fitapply status` | جدول خلاصه آمار و وضعیت آخرین آگهی‌ها در ترمینال |
| `uv run fitapply status --top 10 --min-score 75` | فیلتر سریع برترین موقعیت‌های شغلی با انطباق بالا |
| `uv run fitapply status --export report.md` | ذخیره گزارش جامع متنی در قالب Markdown |
| `uv run fitapply status --html` | **تولید و باز کردن آنی داشبورد گرافیکی در مرورگر (Zero Dependency)** |

---

### جدول دستورات کامل

| دستور | کارکرد |
| :--- | :--- |
| `uv run fitapply audit --resume cv.pdf` | تحلیل و امتیازدهی ATS به فایل رزومه |
| `uv run fitapply parse --resume cv.pdf` | تست استخراج اطلاعات کاندیدا از PDF |
| `uv run fitapply run --resume cv.pdf` | کشف آگهی، امتیازدهی و ارسال رزومه |
| `uv run fitapply status [--html / --export]` | گزارش وضعیت و داشبورد فرصت‌ها |

### امکانات و فلسفه طراحی
- **ضد Overengineering:** تمام امکانات گزارش‌دهی گرافیکی، اسکرپینگ و نقد رزومه بدون اضافه کردن حتی یک فریم‌ورک وب سنگین (مثل Streamlit یا Docker) پیاده شده است.
- **منابع ریموت دلاری رایگان:** اتصال به `Remotive` و `The Muse` در کنار سایت‌های ایرانی (`Jobinja`, `Jobvision`, `IranTalent`) و پلتفرم‌های جهانی (`LinkedIn`, `Indeed`).
- **جلوگیری از ارسال تکراری:** دیتابیس محلی SQLite (`data/jobs.db`) مانع ارسال یا بررسی مجدد آگهی‌های دیده شده می‌شود.
- **حفظ حریم خصوصی و امنیت:** ارسال فقط با نشست مرورگر لوکال شما و بدون درز دادن اطلاعات ورود انجام می‌شود.
